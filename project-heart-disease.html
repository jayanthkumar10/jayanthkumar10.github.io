// 01 The Clinical Context

In medical machine learning, a "False Positive" means a healthy patient gets an unnecessary test. A "False Negative" means a dying patient is sent home.

The goal of this research project was to aggregate highly fragmented, real-world clinical datasets (containing missing values, irregular formats, and imbalanced classes) and train a supervised classification model that could assist cardiologists in early detection.

// 02 The V1 Bottleneck (The Accuracy Trap)

My initial approach was to clean the data, throw it into a standard Random Forest classifier, and optimize for Accuracy. The model quickly achieved 93% accuracy.

This was a dangerous illusion.

Because the clinical dataset was heavily imbalanced (only 7% of the patients actually had the specific heart condition), a "dumb" model that simply predicted "Healthy" 100% of the time would achieve 93% accuracy. The v1 model had a catastrophic False Negative rate. In a clinical setting, this model would kill people.

// 03 The Mathematical Refactoring

I abandoned standard Accuracy as a metric. I restructured the entire training pipeline to optimize strictly for Recall (Sensitivity). I implemented SMOTE (Synthetic Minority Over-sampling Technique) to synthetically balance the dataset during training, preventing the model from collapsing into the majority class.

Furthermore, I introduced a custom cost-sensitive loss matrix into the XGBoost classifier, penalizing the algorithm 10x more for a False Negative than a False Positive.

// 04 The Precision-Recall Trade-off

By forcing the model to aggressively catch potential heart disease (Recall), I inherently sacrificed Precision. The final model generates more False Positives (healthy patients flagged for review).

In a SaaS product, this friction would churn users. In healthcare, this trade-off is legally and ethically mandatory. This nuanced approach to aligning the mathematical loss function with real-world clinical outcomes resulted in a published patent.

# Evaluating strict Recall over standard Accuracy
from sklearn.metrics import recall_score, precision_score, confusion_matrix

def evaluate_clinical_viability(y_true, y_pred_proba, threshold=0.35):
    # Lowering the decision boundary to aggressively catch positives
    y_pred_adjusted = (y_pred_proba >= threshold).astype(int)
    
    recall = recall_score(y_true, y_pred_adjusted)
    precision = precision_score(y_true, y_pred_adjusted)
    tn, fp, fn, tp = confusion_matrix(y_true, y_pred_adjusted).ravel()
    
    if fn > (tp * 0.05):
        raise Exception("Model rejected: False Negative rate too dangerous.")
        
    return {
        "recall": recall,        # Target: > 0.95
        "precision": precision,  # Acceptable degradation
        "false_negatives": fn
    }
