Engineering Philosophy

How I Build Production Code

Build Resilient Systems First

AI fails unpredictably. Every external call needs timeouts, transactional locking, and fallback paths. Async task queues like Celery prevent slow LLM generation from blocking core application threads.

Measure Before Optimizing

Prompt engineering without ground-truth evaluation is just guessing. Systems must have observability (traces, latency, cost metrics) built-in from day one to quantify actual improvement.

Decouple and Modularize

Prompts, retrieval logic, and state orchestration belong in entirely separate layers. Swapping an underlying LLM model (Gemini to Llama) shouldn't require an orchestration logic rewrite.

Context is Engineering

RAG isn't just generic vector similarity. The choice between sparse keyword retrieval (TF-IDF) and dense semantic embeddings is a domain-specific engineering decision driven by scale and offline requirements.
