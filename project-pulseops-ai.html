The Problem

During massive IT outages (e.g., DNS failures, cloud region outages), the very external internet services you rely on to debug the outage might be down. Cloud-based LLMs (OpenAI, Anthropic) become unreachable.

I set out to build an IT incident triage system that could ingest alerts, pull from historical incident playbooks (RAG), and suggest a resolution path—while being completely air-gapped from the internet.

Engineering Decisions

TF-IDF over Dense Vector Embeddings

The Assumption

Modern RAG uses dense vector databases (Chroma, Pinecone) with models like text-embedding-ada-002 to find semantic meaning.

The Decision

IT logs are highly structured and keyword-heavy (e.g., ERR_CONN_REFUSED port 5432). Semantic meaning is less important than exact keyword overlap. I chose TF-IDF (Term Frequency-Inverse Document Frequency). It's lightning-fast, requires no GPU, and runs perfectly offline.

Result: Retrieval latency dropped to <10ms. Eliminated the need to run an embedding model alongside the generation model, freeing up precious VRAM for the local LLM.

Local LLMs (Ollama) over Cloud APIs

The Constraint

The system must function during a complete external network failure.

The Solution

I orchestrated Llama-3.2 locally using Ollama. To make this viable on consumer hardware, the agents are highly specialized. The Parser Agent is given a strictly constrained system prompt to only output JSON, keeping inference fast and preventing the small model from losing context.

Implementation Detail: Sparse Retrieval

Instead of spinning up a heavyweight vector database, the retrieval mechanism uses standard Scikit-Learn to build the TF-IDF matrix and cosine similarity to find the matching playbook.

rag_engine.py Python 
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.metrics.pairwise import cosine_similarity

class PlaybookRetriever:
    def __init__(self, playbooks: list[str]):
        # Sparse representation: Excellent for technical logs and error codes
        self.vectorizer = TfidfVectorizer(stop_words='english')
        self.tfidf_matrix = self.vectorizer.fit_transform(playbooks)
        self.playbooks = playbooks

    def retrieve(self, alert_text: str, top_k=1) -> str:
        query_vec = self.vectorizer.transform([alert_text])
        similarities = cosine_similarity(query_vec, self.tfidf_matrix)
        
        # O(1) lookup speed for exact keyword matching
        best_idx = similarities.argmax()
        return self.playbooks[best_idx]
