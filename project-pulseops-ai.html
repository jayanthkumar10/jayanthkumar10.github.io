An autonomous multi-agent email intake pipeline with a native TF-IDF & Cosine Similarity vector store for automated IT incident triage, engineer allocation, and knowledge base resolution.

Timeline

01

Context & Problem

IT operations teams are often overwhelmed by incoming system alerts, causing delays in manual triage and engineer assignment. This frequently leads to SLA violations and increases the Mean Time to Resolution (MTTR).

Furthermore, when incidents occur, engineers waste valuable time searching through documentation and past records to find the correct remediation steps.

The Objective

Build a lightweight, production-grade autonomous operations assistant that acts as a closed-loop system—parsing email alerts, evaluating risk markers, matching incidents with historical resolutions via a custom vector database, and assigning engineers immediately based on workload.

02

Engineering Constraints

  • Zero External Cloud DB Dependencies To enable local operation without external network dependencies, the vector store had to be designed from scratch in Python using pure TF-IDF indexing and Cosine Similarity mathematics.
  • Dynamic Vocabulary Rebuilding When resolutions are submitted, the index must update dynamically. Rebuilding the document matrix and recalculating IDF weights on-the-fly while keeping the FastAPI server responsive and concurrent.

03

Architecture

I engineered a multi-agent orchestration pipeline that executes sequentially to parse, classify, and allocate incident responses.

🤖

Multi-Agent Intake

Alert intake is handled by specialized agents: EmailReceiverAgent (parsing), TriageAgent (SLA bounding & priority scoring), and AllocationAgent (matching operator workloads & capability scores).

⚙️

Native Vector DB

Built SimpleVectorDB using pure Python mathematics. Computes document and query term frequencies, pre-computes IDF weights, and performs cosine similarity dot products for instant historical matching.

The frontend is designed with a premium CRED dark mode aesthetic, leveraging custom SVG charts and live telemetry console logs. The Python FastAPI backend coordinates state changes and agents, providing a real-time event simulation flow.

04

Impact & Value

100%

Automated Routing

Completely eliminated manual triage delay, instantly assigning incidents to the most qualified engineer.

Self

Improving RAG Index

Engineers' submitted resolutions immediately update the vector search space, ensuring subsequent matching is updated and corrected in real time.
